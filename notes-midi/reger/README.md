# Max Reger — organ material

Verified files currently available:

- `Reger_Op27_Ein_feste_Burg.mid` — *Choral Fantasy*, Op. 27
- `Reger_Op135a_three_chorales.mid` — three chorales from Op. 135a
- `Reger_Op135a_No10_Grosser_Gott.pdf` / `.mid` — Op. 135a No. 10
- `Reger_Op145_No3_Weihnachten.mid` — Op. 145 No. 3, *Weihnachten*

Sources:

- MIDI: Kunst der Fuge, https://www.kunstderfuge.com/reger.htm
- PDF/MIDI: Mutopia Project, https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=1686

The large Op. 46, Op. 57, Op. 59, Op. 65, Op. 67 and Op. 127 score pages were located on IMSLP, but its file server returned a bot-check page to automated downloads; no placeholder files for those works are kept here.
